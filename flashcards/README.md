## 🎯 How to Use

### Manual Study
> **Note:** These are question-only flashcards. Only the **Front** is provided; write or speak your own answer. Companion-answer availability is optional and separate from primary decks (available under `../resources/flashcard-answer-keys/`).

1. Pick one deck and review questions in batches.
2. Attempt answers before checking references.
3. Mark weak cards for targeted review.
4. Revisit weak cards with spaced repetition.

### Digital Tools
- **Anki** - See [anki-export/INSTRUCTIONS.md](./anki-export/INSTRUCTIONS.md)
- **Obsidian** - Use spaced-repetition plugin workflows
- **Notion** - Toggle blocks for self-testing
- **Quizlet** - Copy/paste question sets
