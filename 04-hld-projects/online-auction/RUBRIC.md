
# Online Auction System - Interview Scoring Rubric

| Dimension | Weight | Strong Signal |
|---|---|---|
| Requirements | 10% | Critical correctness and scope boundaries are explicit |
| Estimation | 10% | Numbers influence architecture choices |
| API Design | 15% | Contracts include pagination/idempotency/error semantics |
| Data Model | 15% | Entities and access patterns are coherent |
| Architecture | 20% | Read/write/async paths are clear |
| Deep Dives | 20% | Addresses bottlenecks and failure modes precisely |
| Trade-offs | 10% | Choices tied to measurable goals |

## Score Bands

- 30-35: Strong hire signal
- 22-29: Hire
- 15-21: Lean no hire
- <15: No hire
