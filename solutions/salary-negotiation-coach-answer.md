# 💬 Salary Negotiation Coach Answer

Coach-style answer outlines for three common offer-stage negotiation scenarios.

---

## Script 1: No Competing Offer

### Situation
You have one strong offer, no active competing written offer, and want to improve package quality without damaging close probability.

### Strong response structure
1. Express role intent and appreciation.
2. Confirm package details and decision timeline.
3. Present a component-prioritized ask with rationale.
4. Offer practical flexibility (component swaps, timeline alignment).
5. Request written confirmation of revised terms.

### Example talk track
- "I'm excited about the role and would like to make this work."
- "Could we review the package levers together before I finalize?"
- "My priority is improving total compensation, with flexibility across components if base movement is constrained."
- "If we can align on this structure, I'm comfortable moving quickly."

### Global adaptation
- Use location-adjusted benchmarks and total-comp framing.
- Keep emphasis on role fit, impact scope, and long-term growth.

### India adaptation
- Include fixed vs variable split clarity.
- Explicitly cover joining bonus/buyout and notice-period constraints where relevant.

---

## Script 2: Competing-Offer Pressure

### Situation
You have another process or offer creating timeline and market signal leverage.

### Strong response structure
1. Maintain professionalism; avoid adversarial framing.
2. Present competing context as a market signal, not a threat.
3. Ask for alignment window and component-specific movement.
4. Reiterate preferred employer/role if true.
5. Close with clear next-step timeline.

### Example talk track
- "I want to be transparent that I'm managing another process on a similar timeline."
- "My preference is to join this team if we can align package structure."
- "Given the current gap, could we explore movement on equity/sign-on if base is bounded?"
- "If we can confirm revised terms by <date>, I can make a clean decision quickly."

### Global adaptation
- Compare like-for-like components and risk profile (cash vs equity vs variable).
- Avoid unnecessary confidential disclosures from the other process.

### India adaptation
- Normalize CTC mix carefully (fixed, variable, joining, retention, ESOP/RSU).
- Clarify tax-impact assumptions before comparing outcomes.

---

## Script 3: Best-and-Final Handling

### Situation
Recruiter signals the package is at policy boundary or final decision point.

### Strong response structure
1. Acknowledge boundary signal professionally.
2. Validate final package details and any non-cash clarifications.
3. Decide clearly: accept, decline, or request short final review window.
4. Preserve relationship quality regardless of outcome.

### Example talk track
- "Thanks for being clear on the boundary."
- "Before I decide, I'd like to confirm final details in writing across all components."
- "Based on this structure, I can [accept / decline] by <date>."
- "I appreciate the process and would like to stay connected either way."

### Global adaptation
- Keep closure crisp and documented.
- If declining, communicate respectful rationale without over-detailing private constraints.

### India adaptation
- Confirm final annexure-level details (fixed/variable definitions, payout terms, joining bonus conditions).
- Avoid verbal-only assumptions; rely on written terms.

---

## Universal close checklist

- [ ] Package terms confirmed in writing
- [ ] Start date and timeline confirmed
- [ ] Any conditional clauses reviewed
- [ ] Final decision communicated clearly and professionally
