# Interview Rubric: Token Streaming Server

*Disclaimer: This is candidate-created guidance based on the implemented baseline, not an official company scorecard.*

See source implementations: [streaming_server.py](./python/v1-basic/streaming_server.py).

| Dimension | Strong Signal (Pass) | Weak Signal (Fail) | Concrete Example from Codebase | Implementation Trade-off |
| :--- | :--- | :--- | :--- | :--- |
| **Async Streaming Pipeline** | Domain contracts explicitly enforce an asynchronous streaming pipeline over Server-Sent Events (SSE). Demonstrates O(N) time complexity where N is token count. Properly formats `data: <content>\n\n` SSE events. | Buffers all tokens before returning, breaking O(N) streaming constraints and causing O(N) space growth. | Correctly yields `data: <content>\n\n` immediately after a semantic boundary.<br>**Python:** `yield f"data: {chunk_buffer}\n\n"`<br>**Java:** `out.write("data: " + chunk_buffer + "\n\n"); out.flush();` | Streaming provides low latency for users, but requires the entire stack (web framework, handlers) to be async/streaming compatible, adding complexity. |
| **Cancellation & Abort** | Passively detects client disconnections (e.g., catching `asyncio.CancelledError` in Python) to trigger upstream aborts, ensuring compute resources are freed without external logging of sensitive prompts. | Missing cancellation blocks, meaning ghost threads continue generating tokens for dropped clients. | **Python:** `except asyncio.CancelledError:` block triggering `provider.abort()` and raising.<br>**Java:** `catch (InterruptedException e)` block triggering `provider.abort(); throw e;`. | Early abort saves GPU compute on disconnects, but requires careful error propagation to avoid masking real infrastructure errors. |
| **Chunk Buffering** | Achieves O(M) space complexity where M is the maximum chunk size. Properly flushes buffer on string boundaries. | Yields every micro-token individually causing DOM thrashing, or fails to flush the final remainder buffer. | Checks `Tokenizer.is_boundary(chunk_buffer[-1])` (**Python**) or `Tokenizer.isBoundary(chunk_buffer.charAt(chunk_buffer.length() - 1))` (**Java**) before yielding and clearing the buffer. | Semantic buffering reduces DOM thrashing and network overhead, but slightly increases latency for the very first visual update. |
| **Heartbeat Keep-Alive** | Wraps generation pull in a timeout mechanism and yields a ping event upon timeout. | Fails to inject heartbeats, causing NGINX/ALB disconnects on slow generations. | **Python:** `except asyncio.TimeoutError:` triggering `yield "event: ping\ndata: {}\n\n"`.<br>**Java:** `catch (TimeoutException e)` triggering `out.write("event: ping\ndata: {}\n\n"); out.flush();`. | Keeps connections alive through long LLM stalls, but requires strict timeout loop management to avoid accidental generator cancellation. |
| **Privacy & Tenant Isolation** | Strictly scopes tokens to `tenant_id` and explicitly clears variables (e.g. `chunk_buffer = None`) to enforce boundary. | Uses global caches, leaks tokens between concurrent streams, or leaves sensitive structures in memory. | `finally` block aggressively setting `chunk_buffer = None` and `generator = None` (**Python**) or `chunk_buffer = null; generator = null;` (**Java**). | Explicit garbage collection is safer for tenant isolation but adds boilerplate defensive programming code. |
| **Budget Enforcement** | Halts generation and yields an error event if `max_tokens` is exceeded. | Ignores `max_tokens`, allowing runaway generation and excessive cost. | **Python:** `if max_tokens is not None and processed_token_count > max_tokens:` triggering `.abort()`.<br>**Java:** `if (maxTokens != null && processedTokenCount > maxTokens)` triggering `.abort()`. | Prevents runaway token cost, but might truncate long but legitimate generations if the threshold is too low. |
