# Speculative Decoding: Grading Rubric

This rubric evaluates the candidate's implementation and understanding of the Speculative Decoding verifier algorithm. It explicitly differentiates the core logic (currently implemented) from conceptual extensions.

| Dimension | Strong Signal (L6/L7) | Average Signal (L4/L5) | Weak Signal (L3) |
| :--- | :--- | :--- | :--- |
| **Sampling Math (Current)** | Implements `min(1, pt/pd)` robustly. Protects against zero division or NaN edge cases mathematically (e.g. `pd == 0`). Clearly articulates how rejection acts as residual resampling to guarantee distribution equivalence. | Correctly implements the core acceptance ratio. Understands the basic formula but might struggle to prove the math of the residual fallback offhand. | Fails to implement probabilistic acceptance correctly. Resorts to threshold-based or greedy acceptance that destroys the target distribution guarantee. |
| **Verification Mechanics (Current)** | Executes parallel token scoring logic flawlessly. Accurately handles the sequential rejection short-circuit logic: halting evaluation immediately upon the first rejection and substituting the residual token to preserve causal valid context. Verifies tracking `target_evaluations` incrementing exactly once, incrementing `accepted_tokens_count`, and tracking `kv_cache_length` via `len(accepted)`. | Verification loop halts correctly upon rejection. Replaces rejected token. Minor bugs in tracking `target_evaluations` or KV lengths that are easily spotted and fixed during the interview. | Evaluates all $K$ tokens independently even after a preceding token is rejected, creating a structurally invalid output sequence and violating causal dependency. |
| **Memory Trade-offs & Prefix Caching (Current)** | Defines KV cache growth explicitly in terms of accepted tokens + resampled token/fallback. Understands that a rejected token invalidates subsequent hypothetical KV states, resulting in a prefix-reuse constraint. Can quantify peak VRAM needed for holding two models. | Recognizes that the KV cache must only grow by the valid sequence length. Notes the VRAM penalty of the secondary model but struggles to articulate the prefix-reuse boundary at rejection. | Assumes $K$ tokens always consume $K$ KV slots regardless of acceptance, or fails to recognize the VRAM requirements of loading two full models into memory concurrently. |
| **Architectural Extensions (Optional/Follow-up)** | Provides concrete structural proposals for Medusa/EAGLE heads (eliminating a separate draft model) or Speculative Tree Attention (DAG instead of linear sequence) to boost acceptance bounds. | Can discuss high-level theoretical alternatives like N-gram drafting or temperature-scaled sampling, but cannot detail the API/tensor changes required. | Believes the basic Llama-style sibling-model linear drafting is the only way speculative decoding can be executed. |
