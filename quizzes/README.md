## 🎯 How to Use

### Self-Grading Process
1. Open the quiz file and answer all questions.
2. Mark answers in your notes.
3. Check the matching key in `quizzes/answers/`.
4. Review misses and log weak topics.

### Progress Tracking
- Take once before study for baseline.
- Retake after finishing linked sections.
- Track score trend, not only raw totals.
