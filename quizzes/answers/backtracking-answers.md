## Written Drill Key

| Drill | Strong answer signal |
|---|---|
| A | State is `(index, path)`; `path` contains choices from prior indexes, and each future index remains undecided. |
| B | Each permutation must use every item once; `used` or a swap boundary prevents reusing fixed-prefix items. |
| C | `start` enforces nondecreasing candidate position, so `[2,3]` is generated once rather than again as `[3,2]`. |
| D | Visited is path-local; restoring it lets a cell participate in different paths that do not reuse it in the same path. |
| E | Column and diagonal sets reject attacks in `O(1)` before placing a queen, avoiding full-board scans. |
| F | Call complete search expensive, define pruning and time budgets, record rejected candidates, and provide fallback or partial-plan behavior. |
