## Written Proof Drill Key

| Drill | Strong answer signal |
|---|---|
| A | Replaces the first interval in an optimal solution with the earliest-finishing compatible interval and preserves all later compatibility. |
| B | States that after scanning reachable indexes, only the maximum reachable boundary can affect future reachability; an index beyond it proves failure. |
| C | Shows starts inside a failed segment inherit less surplus before the same failure point, so none can complete that prefix. |
| D | Notes every solution must hit the first uncovered interval, and choosing its end is the latest point that still covers it while maximizing future coverage chance. |
| E | Example: arbitrary coin change can break largest-coin-first, so use DP when future combinations require richer state. |
| F | Calls it a heuristic, defines metrics, guardrails, rollback, and failure modes instead of claiming exact correctness. |
