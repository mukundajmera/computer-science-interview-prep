# GenAI HLD Project Template

Use this for GenAI high-level design projects under `06-genai-systems/02-llm-hld-projects/`.

## Required Files

- `PROBLEM.md`
- `APPROACH.md`
- `DESIGN.md`
- `RUBRIC.md`
- `PITFALLS.md`
- `FOLLOW-UPS.md`
- `COMPARISON.md`
- `STRONG-ANSWER.md`

## Required Design Signals

- User journey and trust boundary.
- Retrieval, model, orchestration, and storage architecture.
- Evaluation plan with offline and online metrics.
- Safety, privacy, and prompt-injection defenses.
- Cost and latency budget.
- Freshness and rollback plan.
- Human review/escalation path where relevant.

## Done Gate

The design must pass HLD readiness plus GenAI-specific currentness, safety, evaluation, cost, and latency checks.
