# Coding Pattern Pack Template

Use this for a complete algorithm pattern pack under `05-coding-problems/`.

## README Contract

- Pattern mental model.
- Recognition cues.
- When to use.
- When not to use.
- Common failure modes.
- Interview scoring focus.
- Ordered problem track.
- Links to quiz, flashcards, and coach answer.

## Problem File Contract

Each numbered problem file should include:

- Problem statement.
- Recognition cue.
- Invariant.
- Algorithm.
- Dry run.
- Complexity proof.
- Pitfalls.
- Follow-ups.
- Related system-design use.

## Assessment Contract

- Add `<pattern>-quiz.md`.
- Add `quizzes/answers/<pattern>-answers.md`.
- Add `flashcards/<pattern>.md`.
- Add `solutions/coding-<pattern>.md` for coach answer if the pattern is in Interview Mode.

## Done Gate

The pack must pass content inventory, markdown links, readiness checks, and portal build.
