## 📋 How to Choose

```
Time until interview?
├── < 1 week → 1-Week Crash Course
│   - Focus on essential patterns and common systems
│   - 4-6 hours daily commitment
│
├── 2-4 weeks → 1-Month Plan (accelerated)
│   - Skip Week 1 fundamentals if already strong
│   - Focus on Weeks 2-4
│
├── 4+ weeks → Full 1-Month Deep Dive
│   - Build strong foundation
│   - Cover all material systematically
│
├── 8-9 weeks → 60-Day Plan (SDE II to Senior)
│   - Structured learning with high-frequency LLD & HLD
│   - GenAI Systems and behavioral prep included
│
├── 12-13 weeks → 90-Day Plan (Staff+)
│   - Extreme depth on storage internals, consensus, and scale
│   - Heavy focus on architecture defense and cross-functional simulations
│
├── Flexible timeline → Topic-Based Plan
│   - Identify weak areas first
│   - Build learning paths around gaps
│
└── Targeting GenAI / LLM interviews?
    ├── 1-2 weeks → GenAI Crash Track
    │   - Focus on RAG + 1-2 HLD systems + key LLDs
    └── 4 weeks → GenAI Deep Dive
        - Full concepts, LLD components, HLD systems, safety & eval
```

## ✅ Progress Tracking

Use checkboxes in each plan to track your progress. We recommend:

1. **Clone the plan** to your own notes or fork the repo
2. **Check off items** as you complete them
3. **Add notes** on areas that need review
4. **Track time spent** to improve future planning

### Sample Progress Format:
```markdown
- [x] ✅ Day 1: Core design patterns (completed in 5 hrs)
- [x] ✅ Day 2: LLD projects (completed - need to review Elevator)
- [ ] 🔄 Day 3: HLD concepts (in progress)
- [ ] Day 4: HLD systems
```

## 📌 General Study Tips

1. **Active recall** - Don't just read, practice explaining concepts
2. **Time yourself** - Practice under interview conditions (45-60 min)
3. **Draw diagrams** - Sketch class diagrams (LLD) and architecture (HLD)
4. **Mock interviews** - Practice with peers or record yourself
5. **Review mistakes** - Keep a log of common errors
